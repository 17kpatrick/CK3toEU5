# CK3 holding building name fragments -> EU5 building types (in_game/common/building_types).
# A CK3 building whose name contains the ck3 fragment adds one EU5 building at the mapped location.
# The first matching link wins per CK3 building; each EU5 building is added at most once per location.
#
# Buildings written here are GOVERNMENT-OWNED (tag = country) and the state pays their upkeep, so
# only building types vanilla EU5 state-owns belong here: forts, cathedrals, universities. The
# pop-owned economy (temples, marketplaces, guilds...) comes from town setups instead - a developed
# CK3 county earns those through its town/city rank, the channel vanilla uses.

# Sacred landmarks: CK3 holy-site special buildings (grand temples, famous cathedrals and mosques)
# become EU5 cathedrals, which vanilla state-owns the same way. Ordinary temple_01..04 convert to
# nothing; every town setup already includes a pop-owned temple.
link = { eu5 = cathedral ck3 = holy_site ck3 = cathedral ck3 = hagia_sophia ck3 = notre_dame ck3 = dome_of_the_rock ck3 = damascus_mosque ck3 = duomo_florence ck3 = temple_of_uppsala }
# Forts: vanilla's own castles and stockades already transfer to the converted map (through town
# setups and re-tagged building_manager entries), so the regional fort balance is covered. Only
# famous unique walls and fortress wonders add castles on top; ordinary CK3 walls - even top-tier
# ones, which late-game saves have on every second holding - convert to nothing. Every castle here
# is crown-owned and paid for monthly out of the budget capped by crown_building_allowance.
# _castle (with the underscore) catches named castle wonders like alamut_castle without matching
# the baseline castle_01..04 buildings every CK3 castle holding has.
link = { eu5 = castle ck3 = theodosian_walls ck3 = aurelian_walls ck3 = gongsanseong_fortress ck3 = jaisalmer_fort ck3 = hotin_fort ck3 = walls_of_benin ck3 = walls_of_genoa ck3 = kano_walls ck3 = york_walls ck3 = _castle ck3 = alcazar ck3 = tower_of_london }
link = { eu5 = university ck3 = university ck3 = madrasa }
